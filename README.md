## 🎯 정산 시스템 프로젝트

----
```
배달 서비스(배달의 민족, 요기요)를 참고하여 가게 업주(Owner)가 주문 정보와 정산 정보를 효율적으로 조회하고 관리할 수 있는 프로그램입니다.

이 프로젝트는 Spring Batch를 활용한 대용량 데이터 처리에 중점을 두고 있으며, 안정적인 정산 시스템을 구축하는 것을 목표로 합니다.
대량의 주문 데이터를 빠르고 정확하게 처리하기 위해 배치 프로세스를 설계하고 최적화했으며, 업주가 실시간으로 정산 내역을 확인할 수 있도록 구현했습니다.
```


### ⚒️ 기술 스택

----

**Backend** : `Spring Boot`, `Spring Batch`, `JPA`, `QueryDSL`  
**Database** : `MySQL`  
**Frontend** : `Flutter`
